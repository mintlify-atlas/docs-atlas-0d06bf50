LWXGL is a lightweight shared library that lets you build X11 desktop applications in C or C++. It provides a complete set of GUI building blocks — buttons, text labels, inputs, checkboxes, a scrollable console, and more — plus a raster image canvas with drawing primitives, TGA/XBM image loading, and embedded OpenGL rendering, all behind a simple procedural C API.

## Quick example

```c example.c
#include <libLWXGL.h>

void on_every_frame(int frame, float dt) {
    static float circle_x = 50, circle_speed = 150;
    ImmediateTextF(10, 10, CLR_WHITE, "Elapsed time: %.1f seconds", GetElapsedTime());
    circle_x += circle_speed * dt;
    if (circle_x >= 336 || circle_x <= 0) circle_speed *= -1;
    ImmediateEllipse(circle_x, 80, 64, 64, CLR_WHITE, CLR_ORANGE);
}

int main() {
    CreateWindow(400, 250, "Example Window", CLR_BLUE);
    CreateButton(0, 270, 210, 120, 30, 0xF4, 0xF5, 0xF2, "Quit", DeleteWindow);
    MainWindowLoop(60, on_every_frame);
    TerminateWindow();
}
```

Compile with: `gcc -o example example.c -lLWXGL`

<Steps>
  <Step title="Install LWXGL">
    Build from source with `make` and install with `make install`. See [Installation](/installation) for full details.
  </Step>
  <Step title="Include the header">
    Add `#include <libLWXGL.h>` to your source file and link with `-lLWXGL`.
  </Step>
  <Step title="Create a window">
    Call `CreateWindow(width, height, title, bgcolor)` before any other LWXGL function.
  </Step>
  <Step title="Run the main loop">
    Call `MainWindowLoop(fps, callback)` to start rendering, then `TerminateWindow()` after it returns.
  </Step>
</Steps>
